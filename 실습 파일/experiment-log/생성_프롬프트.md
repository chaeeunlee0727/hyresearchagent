# experiment-log Skill 생성과 실행 프롬프트

## 생성 요청

```text
앞에서 만든 experiment-log 실행 계약을 바탕으로
.claude/skills/experiment-log/SKILL.md를 만들어줘.
원본 로그와 설정, 결과 파일은 절대 수정하지 말고 읽기만 해줘.
관찰된 사실과 실패 원인 후보를 구분하고, 후보마다 확인 방법을 붙여줘.
다음 실험은 승인 대기 후보까지만 만들고, 우선순위를 확정하거나 실행하지 마.
저장 위치는 실행 계약과 research README를 따르고, 생성 전에 어떤 파일을 만들고 지울지 먼저 보여줘.
SKILL.md를 만든 뒤 루트의 experiment-log_실행계약.md에 적힌 내용이
전부 옮겨졌는지 확인하고 알려줘. 확인 후 내 승인을 받아 작업용 계약 파일을 정리해줘.
```

## 실행 요청

자신의 연구 기록에서 구조화할 대상 실험을 고릅니다. 비교가 필요하면 기준 실험도 함께
지정합니다. 저장할 프로젝트를 생략한 요청으로 중지 동작을 먼저 확인할 수 있습니다.

```text
[대상 실험]을 정리해줘.
원본은 [메모 경로], [설정 파일 경로], [결과 파일 경로]야.
비교할 기준 실험은 [기준 실험]이야.
```

중지를 확인한 뒤 프로젝트를 지정해 다시 요청합니다.

```text
[대상 실험]을 정리해줘. 프로젝트는 [프로젝트명]이야.
원본은 [메모 경로], [설정 파일 경로], [결과 파일 경로]야.
비교할 기준 실험은 [기준 실험]이야.
```

기준 실험과 비교하지 않는 작업에서는 기준 실험 문장을 생략합니다.

## 검수 포인트

- 결과 표의 모든 수치에 근거 파일과 위치가 붙어 있는가
- 비교값은 평가 데이터셋, split, 클래스와 마스크 규칙이 같은 항목에만 계산됐는가
- 연구자 메모의 관찰과 원본에서 계산한 비교 결과가 구분됐는가
- 실패 원인 후보마다 근거와 확인 방법이 붙어 있는가
- 다음 실험 후보가 한 번에 바꿀 변수를 분명히 하고 승인 대기로 남았는가
- 기준 실험 원본이 없을 때 비교를 생략해 진행하지 않고 연구자에게 물었는가
- 원본 파일이 수정되지 않았는가
- 완료 보고에 생성·수정 파일과 갱신한 index가 포함됐는가
