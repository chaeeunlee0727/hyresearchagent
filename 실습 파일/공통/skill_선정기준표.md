# Skill 선정 기준표

반복 업무를 Skill 후보로 평가할 때 사용하는 기준표. 각 업무를 다섯 기준으로
상·중·하 평가하고, 종합 판단과 근거를 적는다. 점수는 순위를 돕는 보조 수단이며,
합계가 같으면 입력 안정성과 검증 가능성을 우선한다.

## 다섯 기준

| 기준 | 확인 질문 |
|---|---|
| 반복성 | 같은 형태의 요청이 앞으로도 계속 들어오는가? |
| 입력 안정성 | 시작에 필요한 입력의 종류와 형식이 매번 비슷한가? |
| 출력 안정성 | 결과가 들어갈 파일, 위치, 형식이 정해져 있는가? |
| 검증 가능성 | 결과가 맞는지 기대 행동과 대조해 시험할 수 있는가? |
| 사람 판단 필요도 | 절차 중간에 연구자의 가치 판단이 얼마나 자주 필요한가? |

사람 판단 필요도는 낮을수록 Skill에 적합하다. 나머지 넷은 높을수록 적합하다.

## Skill로 만들지 않는 일

다음은 반복되더라도 연구자의 판단으로 남긴다.

- 연구 주제와 연구 질문의 확정
- 연구 공백인지 아닌지의 최종 판단
- 다음 실험의 선택과 실행 승인
- 논문 주장의 채택과 최종 원고 승인
