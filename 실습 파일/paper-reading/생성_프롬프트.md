# paper-reading Skill 생성 프롬프트

실행 계약을 작성한 뒤, 작업공간 루트에서 Claude에게 요청한다.

## 생성 요청

```text
앞에서 만든 paper-reading 실행 계약과 현재 llm_wiki의 운영 규칙을 바탕으로
.claude/skills/paper-reading/SKILL.md를 만들어줘.
기존 템플릿과 README의 규칙은 복제하지 말고 필요한 순서에서 참조해줘.
SKILL.md를 만든 뒤 루트의 paper-reading_실행계약.md에 적힌 내용이
전부 옮겨졌는지 확인하고 알려줘. 확인 후 내 승인을 받아 작업용 계약 파일을 정리해줘.
생성하기 전에 어떤 파일을 만들고 지울지 먼저 보여줘.
생성한 뒤에는 호출 조건, 누락 입력 처리, 저장 위치, 중지 조건 중
모호한 부분을 스스로 점검해서 보고해줘.
```

## 검토 포인트

생성된 SKILL.md에서 확인할 것.

- 사용 조건: 어떤 요청에서 이 Skill이 쓰이는지 분명한가
- 입력 게이트: 필수 입력이 없으면 질문하고 멈추는가
- 절차: 템플릿과 README를 올바른 순서로 참조하는가
- 출력과 저장: 파일 위치와 완료 보고 항목이 계약과 일치하는가
- 중지 조건: 실행 계약의 Stop / Ask가 빠짐없이 옮겨졌는가
- 책임 중복: 템플릿 본문이나 README 절차 전문이 복사돼 들어오지 않았는가
- 단일 원본: 계약에 적은 내용이 전부 SKILL.md로 옮겨졌는가. 확인한 뒤 승인한 작업용 계약 파일만 Claude에게 정리하도록 요청한다

## 자체 점검 요청

```text
방금 만든 SKILL.md를 기존 llm_wiki/README.md, llm_wiki/research/README.md,
llm_wiki/papers/_template.md와 비교해서 같은 규칙이 두 곳에 적혀 있는 부분을 찾아줘.
중복된 문장은 참조로 줄이는 수정안을 제안하고, 내 승인 전에는 고치지 마.
```
