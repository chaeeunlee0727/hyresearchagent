# paper-reading Skill 테스트 기록

실행하기 전에 기대 행동을 먼저 적고, 실행 후 실제 행동과 대조합니다.
실패하면 원인을 호출 조건, 입력 게이트, 저장 위치, 완료 보고 중 하나로 분류하고,
해당 문장만 최소 수정한 뒤 실패한 테스트를 다시 실행합니다.

## 기록표

| 시나리오 | 입력 | 기대 행동 | 실제 행동 | 통과 | 수정 |
|---|---|---|---|---|---|
| 정상 | 식별 가능한 새 논문과 접근 가능한 원문 | Skill 호출, 템플릿 적용 저장, 상태·index·log 갱신, 완료 보고 |  |  |  |
| 누락 | 논문을 식별할 수 없는 요청 | 어떤 논문인지 질문하고 중지, 빈 페이지를 만들지 않음 |  |  |  |
| 재실행 | 이미 처리한 동일 논문 | 기존 페이지 확인, 필요한 부분만 갱신, 중복 페이지·링크·로그 없음 |  |  |  |

## 실패 신호

- 정상: 잘못된 위치 저장, 허브·index·log 갱신 누락, 완료 보고 항목 누락
- 누락: 추측으로 생성, 확인하지 않은 메타데이터 기록, 질문 없이 빈 파일 생성
- 재실행: 중복 페이지, 중복 링크, log 중복 기록

## 테스트 입력 준비

정상 입력에는 자신의 연구와 관련된 논문 한 편의 DOI, arXiv ID, 공식 URL 또는
원문 PDF를 사용합니다. 테스트 전에 예상 파일명과 도달할 상태를 기록합니다.

누락 입력에는 PDF와 식별 정보가 모두 없는 요청을 사용합니다. 미식별 PDF를 제공하는 경우에는
`attachments/_unidentified/`에 사본이 보관되고 논문 페이지는 생성되지 않는지 별도로 확인합니다. 재실행에서는 정상
입력과 같은 요청을 한 번 더 사용합니다.
