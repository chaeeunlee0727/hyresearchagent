# Skill 실행 계약 템플릿

SKILL.md를 만들기 전에 Skill의 행동을 한 장으로 고정하는 문서.
호출 조건, 입력, 처리 과정, 출력, 중단 조건과 검증 기준을 작성한다.
내용 형식은 기존 템플릿과 README가 이미 정하고 있으므로 여기에는
언제 시작하고, 무엇이 있어야 하고, 어디에 저장하고, 언제 멈추는지만 적는다.

```markdown
# <skill-name> 실행 계약

## Trigger
- 이 Skill을 호출해야 하는 요청의 형태
- 호출하면 안 되는 비슷한 요청

## Input
- 필수: 없으면 시작하지 않고 질문할 입력
- 선택: 있으면 결과가 좋아지는 입력

## Process
- 단계 순서. 기존 템플릿과 README 규칙은 복제하지 않고 참조로 가리킨다.
- 같은 입력이 다시 들어왔을 때의 동작

## Output
- 생성·갱신할 파일과 위치
- 완료 보고에 반드시 들어갈 항목

## Stop / Ask
- 진행을 멈추고 사람에게 물어야 하는 조건

## Validation
- 실행을 끝내기 전에 실제 파일과 대조할 항목
- 다시 실행해도 중복이 생기지 않았는지
```
