# Skill 품질 체크리스트

Skill이 반복 실행 도구로서 안정적인지 평가하는 공통 기준이다.
연구 내용의 타당성은 해당 분야의 검증 규칙과 연구자의 판단으로 따로 확인한다.
새 Skill을 만들 때마다 실제 실행 결과를 근거로 이 표를 작성한다.

## 여덟 기준

| 기준 | 확인 질문 |
|---|---|
| Trigger | 필요한 요청에서 호출되고 무관한 요청에서는 호출되지 않는가? |
| Input gate | 필수 입력을 확인하고 부족하면 질문하는가? |
| Procedure | 현재 작업공간의 규칙과 템플릿을 올바른 순서로 참조하는가? |
| Output contract | 정해진 파일, 위치, 형식과 완료 보고를 지키는가? |
| Stop / Ask | 추측이나 권한 밖 행동 전에 멈추는가? |
| Idempotency | 같은 입력에서 중복 파일, 링크와 기록을 만들지 않는가? |
| Scope | 연구자와 다른 Agent의 책임을 침범하지 않는가? |
| Testability | 정상, 누락, 충돌과 재실행 사례의 기대 행동을 확인할 수 있는가? |

## 평가 기록 방법

기준마다 다음 내용을 남긴다. 실행 기록 없이 인상만으로 통과 판정하지 않는다.

- 결과: 통과 / 보완 필요 / 해당 없음
- 근거: 테스트 기록, 생성 파일, 변경 내역 또는 완료 보고의 위치
- 문제: 기대 행동과 실제 행동의 차이
- 수정: `SKILL.md`에서 바꾼 최소 항목
- 재검증: 다시 실행한 시나리오와 결과
