# paper-reading Skill 테스트 기록 완성예시

아래 표는 테스트 기록 방법을 보여 주는 예시입니다. 대괄호 안의 내용은 실제 실행에서
확인한 값으로 바꿉니다.

| 시나리오 | 실제 행동 | 통과 | 수정 |
|---|---|---|---|
| 정상 | `[논문 페이지]` 생성, `[도달 상태]` 기록, 서지 허브·index·log 갱신 | 통과 | 없음 |
| 누락(PDF·식별 정보 없음) | 어떤 논문인지 질문하고 중지, 실행 전후 Wiki 파일 불변 | 통과 | 없음 |
| 재실행 | 기존 페이지와 허브·log를 확인하고 중복 생성 없이 종료 | 통과 | 없음 |

## 정상 실행에서 확인할 항목

- 서지 정보가 외부 서지 DB와 대조됐습니다.
- 실제로 읽은 원문 판본과 근거 위치가 기록됐습니다.
- 페이지 상태가 수행한 단계와 일치합니다.
- 필요한 허브, index와 log가 갱신됐습니다.
- 확인하지 못한 내용은 확정된 사실로 기록되지 않았습니다.

## 누락·재실행 검증

누락 입력과 동일 입력 재실행 전후에 생성·수정된 파일을 비교합니다. 예상하지 않은
변경이 있으면 파일과 변경 내용을 기록하고, 원인이 있는 Skill 문장만 수정한 뒤 같은
입력으로 다시 확인합니다.
